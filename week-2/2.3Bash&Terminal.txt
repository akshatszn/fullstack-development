awk is a scripting language designed specifically for text processing and data extraction. can be used in terminal i guess
📝 1. The Core Syntax
Every awk command generally follows this simple structure:

bash
awk 'pattern { action }' filename
Pattern: When should awk do the action? (If empty, it does the action on every line).
Action: What should awk do? (Usually it is printing something out).
Note the single quotes ' ' around the pattern and action block!

🧩 2. The Magic Variables
awk automatically breaks a line of text into columns (which it calls "fields"). It uses special variables to represent them:

$0 = The entire line.
$1 = The 1st column.
$2 = The 2nd column, and so on...
NR = The current Row/Line Number (Number of Records).
NF = The Total Columns on the current line (Number of Fields).

🚀 3. Beginner Commands (Copy & Paste Examples)
Let's say you have a file named students.txt that looks like this:

text
Alice 85 Math
Bob 92 Science
Charlie 78 History
1. Print Specific Columns
Print only the names (1st column) and subjects (3rd column):

bash
awk '{print $1, $3}' students.txt
2. Print with Line Numbers
Use the NR variable. This prints: "1. Alice", "2. Bob", etc.

bash
awk '{print NR".", $1}' students.txt
3. Basic Filtering (Patterns)
Print the entire line ($0) ONLY if their score (2nd column) is greater than 80:

bash
awk '$2 > 80 {print $0}' students.txt
4. Changing the Separator (The -F Flag)
By default, awk splits strings by spaces. What if your file is separated by commas (like a .csv file)?

text
Alice,85,Math
Tell awk the separator is a comma using -F",":

bash
awk -F"," '{print $1, $3}' students.csv
5. Adding BEGIN and END Blocks
BEGIN block runs once before processing the file. END block runs once after finishing the file.

bash
awk 'BEGIN {print "--- Students Chart ---"} {print $1} END {print "----------------------"}' students.txt
💡 Pro Tip for Beginners: The most common and practical way you will use awk as a beginner developer is to grab a specific piece of data from the output of another command using a "pipe" (|). Example:

bash
ls -l | awk '{print $9}' # This lists only the filenames from the ls -l output

Got it! Here are 4 quick, single-line examples you can copy directly:

1. Print the 1st and 3rd columns of a file:

bash
awk '{print $1, $3}' data.txt
2. Print only the lines where the 2nd column is greater than 50:

bash
awk '$2 > 50 {print $0}' data.txt
3. Change the separator to a comma (for CSVs) and print the 1st column:

bash
awk -F"," '{print $1}' data.csv
4. Count and print the total number of lines in a file:

bash
awk 'END {print NR}' data.txt
